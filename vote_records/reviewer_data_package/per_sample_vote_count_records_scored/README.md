# Scored per-sample vote-count records (with explicit MMV/SC columns)

This folder supersedes `../per_sample_vote_count_records/` for verification purposes.
The original folder is left unchanged for provenance (it is exactly what the
experiment runner wrote); this folder adds explicit, pre-computed columns so that
reviewers do not have to re-derive MMV and self-consistency predictions by hand.

## Why this folder exists

An external review of the manuscript found that `pred`/`correct` in the original
per-sample CSVs conflate two different rules: they always reflect a plurality
("self-consistency") prediction, even for MMV, which is a *different* rule that
abstains when no label reaches a strict majority of the original k. This made it
easy to misread the released data as already reflecting MMV's abstention behaviour,
when in fact it does not. This folder fixes that by giving MMV and self-consistency
their own explicit prediction and correctness columns, generated by
`scripts/regenerate_all.py` directly from the original `votes` field -- no numbers
were retyped by hand.

## Columns

`id, text, gold, gold_multi, votes, mmv_pred, sc_pred, mmv_correct, sc_correct, parser_failure, top_votes, K, confidence_mmv, confidence_sc`

- `mmv_pred`: the Minimal Majority Vote prediction -- the plurality label if it holds
  a strict majority of the original k, otherwise the literal string `ABSTAIN`.
- `sc_pred`: the self-consistency (classical, always-predict) prediction -- the
  plurality label, with ties broken deterministically by first-in-fixed-class-order.
  `sc_pred` is `ABSTAIN` only when every one of the k calls failed to parse
  (`parser_failure = 1`); self-consistency never abstains once at least one valid
  vote exists.
- `mmv_correct` / `sc_correct`: 1 if the corresponding prediction matches gold
  (multi-label-tolerant for GoEmotions, i.e. credited if it matches any label in
  `gold_multi`), 0 otherwise. Both are 0 when the corresponding prediction is
  `ABSTAIN`.
- `parser_failure`: 1 if none of the k calls parsed into a valid label for this
  sample (`sum(votes.values()) == 0`), 0 otherwise. This is the same
  parser-failure definition used in Table 2 and is independent of MMV's
  strict-majority abstention rule.
- `confidence_mmv` / `confidence_sc`: `votes[pred] / K`, rounded to 4 decimal
  places, for the corresponding prediction; 0.0 when that prediction is `ABSTAIN`.

## Regenerating this data (and Tables 1, 2, 5, 7) yourself

```bash
cd llm_majority_vote_ollama
python3 scripts/regenerate_all.py
```

This reads only the original, unmodified files in `../per_sample_vote_count_records/`
and prints/saves `table1_regenerated.csv`, `table2_regenerated.csv`,
`table5_regenerated.csv`, and `table7_regenerated.csv`, plus a fresh copy of every
file in this folder. Every number in Tables 1, 2, 5, and 7 of the manuscript can be
reproduced this way from the raw released votes -- nothing downstream of the raw
`votes` field is hand-typed anywhere in the paper.
