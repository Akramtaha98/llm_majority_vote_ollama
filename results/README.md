# results/

Result tables of the paper (`T_*.csv`), produced by `revision/analyze_unified.py` and copied here by `revision/package_release.sh`:

* `tables_main/`: 3B and 7B models, full samples, three repeats (Tables 1-5 of the paper, Supplement S1-S10)
* `tables_32b/`, `tables_70b/`: larger-model check (Table 6)

Per-call outputs are in the release tarball `unified_runs_v2.0-revision.tar.gz`.
